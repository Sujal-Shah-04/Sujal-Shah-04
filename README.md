## 🔥 Featured Projects

### 🌿 AI Plant Disease Detection System — *Production Deployed*
> **Stack:** Python · TensorFlow · PyTorch · CNN · OpenCV · Grad-CAM · FastAPI · Flutter

- 🎯 **92% accuracy** on a 50K-image, 38-class dataset using transfer learning + augmentation — production-grade, not a demo
- ⚡ Served via **FastAPI** with **<200ms latency** under real-world load
- 🔍 **Grad-CAM heatmaps** — farmers see *exactly* why the model flagged a disease
- 📴 **Flutter mobile app** works fully offline — built for rural farmers with zero connectivity

### 🧓 XAI-Care — Explainable Multimodal AI for Elderly Assistance
> **Stack:** Python · TensorFlow · FastAPI · Grad-CAM · SHAP · Wearable Sensors

- 🩺 Fuses **wearable sensor streams + camera data** for real-time fall detection & health monitoring
- 🔬 **SHAP + Grad-CAM** modules surface model reasoning to caregivers — AI that explains itself
- ⚡ **Sub-second alert delivery** via FastAPI live monitoring dashboard
- 🏥 Designed for non-technical users — trust and usability baked into the architecture

---

### 🍽️ Restaurant POS System — *Fully Offline*
> **Stack:** Flutter · FastAPI · SQLite · JWT Authentication

- 📴 **Zero internet dependency** — full order tracking for table and takeaway workflows
- 🔐 Role-based access control (Admin / Staff) with **JWT authentication**
- 📊 Analytics dashboard — daily revenue, top-selling items, peak-hour trends
- 🗄️ **SQLite** persistence ensures data integrity with no cloud dependency
